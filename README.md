# Telegram SOCKS5 Proxy Scanner & Hunter 🔍⚡

یک جعبه‌ابزار قدرتمند به زبان پایتون جهت اسکن و استخراج خودکار آی‌پی‌ها، شناسایی پورت‌های باز با **Nmap** و تست اتصالات **SOCKS5** برای سرورهای تلگرام.

این مخزن دو روش اجرایی را در اختیار شما قرار می‌دهد:
1. **روش همه‌کاره و خودکار (All-in-One):** پینگ همزمان، اسکن پورت‌ها، حل خودکار انکودینگ، تست موازی پروکسی‌ها و تولید مستقیم لینک‌های تلگرام (`t.me/socks?...`).
2. **روش دستی و مرحله‌به‌مرحله (Step-by-Step):** اجرای جداگانه اسکن Nmap با دستور خط فرمان پاورشل، استانداردسازی انکودینگ خروجی، و سپس تست اختصاصی پورت‌ها.

---

## ⚙️ پیش‌نیازها

- **سیستم‌عامل:** ویندوز یا لینوکس (پیشنهاد: ویندوز با PowerShell)
- **ابزار Nmap:** باید روی سیستم نصب بوده و به متغیرهای محیطی سیستم (`PATH`) اضافه شده باشد.
  - بررسی نصب: دستور `nmap -v` را در ترمینال اجرا کنید.
- **پایتون:** نسخه 3.8 یا بالاتر
- **نصب کتابخانه‌ها:**
  ```bash
  pip install -r requirements.txt
  ```

---

## 🚀 روش اول: اجرای تمام‌خودکار (All-in-One) — *پیشنهادی*

در این روش نیازی به اجرای دستورات دستی یا تبدیل فایل‌ها ندارید. برنامه خودش پینگ می‌گیرد، پورت‌ها را اسکن کرده، تست می‌کند و لینک‌های آماده تلگرام تحویل می‌دهد.

### ۱. ورودی‌ها (یکی از دو حالت یا هر دو):
- **فایل `ip.txt`:** آی‌پی‌های خام خود را (هر خط یک آی‌پی) در این فایل قرار دهید.
- **فایل `config.txt`:** می‌توانید کانفیگ‌های خود شامل `vmess://` (استخراج Base64 خودکار)، `vless://`، `trojan://` یا `ss://` را مستقیماً داخل آن بریزید؛ برنامه خودش آی‌پی‌های آنها را استخراج و پاک‌سازی می‌کند.

### ۲. اجرا:
```bash
python IP_or_config_to_socks-tel.py
```

### ویژگی‌های حالت خودکار:
- پینگ فوق‌سریع به‌صورت ناهمگام (Asyncio با ظرفیت همزمانی ۲۰۰ پینگ همزمان)
- اسکن اتوماتیک پورت‌ها با فلگ `--min-rate 2000` و رفع خودکار ارورهای انکودینگ خروجی
- تست موازی با ۱۰۰ ترد (Thread) برای بررسی پاسخ‌دهی به سرور تلگرام (`149.154.167.91:443`)
- خروجی نهایی: ذخیره لینک‌های آماده در فایل `Tel_socks.txt`

## 🛠️ روش دوم: مرحله‌به‌مرحله (Step-by-Step)

اگر قصد دارید یک آی‌پی خاص را بررسی کنید یا ترجیح می‌دهید مراحل را به‌صورت تفکیک‌شده پیش ببرید، مراحل زیر را دنبال کنید:

### گام اول: اسکن پورت‌های باز با PowerShell و Nmap
در پاورشل، دستور زیر را اجرا کنید (به‌جای `IP`، آدرس آی‌پی موردنظرتان را بنویسید):

```powershell
nmap -p- --open -oG - IP | Select-String "Ports:" | ForEach-Object { $_ -match "Ports: (.*)" > $null; $ports = $Matches[1]; $ports -split ',' | ForEach-Object { if ($_ -match '(\d+)/open') { $matches[1] } } } | Out-File -FilePath "IP.txt"
```
*خروجی این دستور فایلی متنی شامل پورت‌های باز آی‌پی هدف به نام `<IP>.txt` خواهد بود.*

---

### گام دوم: اصلاح انکودینگ فایل (UTF-8 Fixer)
دستورات پاورشل معمولاً خروجی را با انکودینگ UTF-16 ذخیره می‌کنند. برای جلوگیری از خطاهای متنی در پایتون، این اسکریپت را اجرا کنید:

```bash
python utf8_fixer.py
```
- نام فایل مرحله قبل (مثلاً `62.220.126.56.txt`) را وارد کنید.
- با فشردن کلید `y` تایید کنید تا نسخه سالم در فایلی به نام `fixed_<IP>.txt` ذخیره شود.

---

### گام سوم: تست پروکسی SOCKS5
در نهایت برای تست پورت‌های استخراج‌شده:

```bash
python socks_tester.py
```
- آدرس آی‌پی هدف را وارد کنید.
- برنامه فایل `fixed_<IP>.txt` را می‌خواند و پورت‌ها را با ۹۰ ترد موازی تست می‌کند.
- پورت‌های سالم در فایلی به نام `<IP>-works.txt` ذخیره می‌شوند.
